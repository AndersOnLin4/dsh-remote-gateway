# 项目组成

> DSH 远程网关：一个架在 DeepSeek Harness（DSH）前面的轻量网关，提供登录鉴权、手机端监控/回复、反向代理与数据过滤。

## 目录结构

```
G:\Andersonlin4-design 手机远控项目\
├─ PLAN.md                     # 方案设计（评审稿）
├─ DEPLOY.md                   # 部署与使用（含真实地址，仅本机）
├─ 归档\                       # 本次会话档案（本目录）
└─ gateway\                    # 网关主体
   ├─ requirements.txt         # 依赖：fastapi / uvicorn[standard] / httpx / python-multipart / zstandard
   ├─ run.py                   # 启动入口（uvicorn）
   ├─ start_all.py             # 一键启动：拉起 DSH（若未运行）+ 网关，日志重定向
   ├─ start-all.cmd            # 启动脚本（%~dp0 相对路径，兼容中文目录）
   ├─ stop-all.cmd             # 停止脚本（按端口 8080/3080 结束进程）
   ├─ .env                     # 登录密码与签名密钥（自动生成，勿外传）
   ├─ .venv\                   # Python 虚拟环境（隔离，未污染系统）
   ├─ app\
   │  ├─ main.py               # FastAPI 应用：路由、登录、鉴权中间件、控制接口
   │  ├─ config.py             # 配置：路径/端口/密钥（读 .env 自动生成）
   │  ├─ auth.py               # HMAC 会话 Cookie、登录限速
   │  ├─ monitor.py            # 端口探测、日志 tail、工作区名解码
   │  ├─ dsh_manager.py        # DSH 进程托管（启/停/重启，stdout 落盘）
   │  ├─ sessions.py           # 会话列表（索引缓存）+ 尾段读取（zstd）+ 发消息
   │  └─ proxy.py              # 反向代理：HTTP/WS、Host/Origin 重写、HTML 注入、
   │                           #   gzip 压缩、缓存策略、history 数据过滤、问题监听
   └─ static\                  # 移动端前端（无构建，原生 HTML/JS/CSS）
      ├─ index.html            # 登录 + 三 Tab（监控/会话/日志）+ 会话预览 + 回复框
      ├─ app.js                # 前端逻辑（api 封装、轮询、选择题卡片、预热）
      └─ style.css             # 移动优先深色样式
```

## 模块职责

| 模块 | 职责 |
|---|---|
| `main.py` | 路由与鉴权中间件；`/gw/*` 全部接口；DSH 页面代理挂根路径 |
| `proxy.py` | 核心代理：重写 Host/Origin 过 DSH 信任栅栏；注入 polyfill/移动端样式/预加载；gzip；immutable 缓存；`session.history` 数据过滤；WS 帧监听（选择题） |
| `sessions.py` | 会话索引（不读大文件）、zstd 尾段提取、session.prompt 转发 |
| `auth.py` | 登录鉴权、限速、审计配合 |
| `dsh_manager.py` | DSH 进程生命周期管理 |
| `monitor.py` | 状态探测与日志 |

## 接口清单（均需登录，除 /gw/login）

| 接口 | 说明 |
|---|---|
| `POST /gw/login` / `POST /gw/logout` / `GET /gw/session` | 登录 / 退出 / 会话状态 |
| `GET /gw/status` | DSH 运行状态 + 会话统计 |
| `GET /gw/sessions` | 会话列表（标题/工作区/轮数/token/活跃） |
| `GET /gw/session/{id}/tail` | 会话尾段（过滤后的重要节点） |
| `POST /gw/session/{id}/send` | 给会话发消息（session.prompt RPC） |
| `GET /gw/questions?sid=` | 挂起的选择题 |
| `POST /gw/session/{id}/answer` | 提交选择题答案（respond RPC） |
| `POST /gw/control/{start\|stop\|restart}` | DSH 进程控制 |
| `GET /gw/log` | DSH 日志 tail |
| `GET /dashboard` `/static/*` | 前端 |
| `/` 及任意路径（登录后） | 反向代理 DSH 原版 UI |

## 部署方式

- 启动：双击 `gateway\start-all.cmd`（自动拉起 DSH + 网关）
- 停止：双击 `gateway\stop-all.cmd`
- 自启：`启动文件夹\DSH Remote Gateway.lnk`（登录 Windows 自动运行）
- 日志：`G:\harness\logs\`（dsh.log / gateway.out.log / gateway-audit.log）
- 访问：仪表盘 `/dashboard`；完整控制台 `/`；外网走 Tailscale HTTPS
