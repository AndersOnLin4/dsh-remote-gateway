## 详细时间线

### 01 · 方案设计
- 调研 `G:\harness`：确认 `dsh web` 跑在 127.0.0.1:3080，**DSH 无任何鉴权**（官方明确），权限预设 `danger-full-access`，`dsh-home` 存有 API 密钥。
- 结论：绝不对公网直连 3080，必须在前面加认证层。
- 定稿方案（PLAN.md）：FastAPI 网关(:8080) + 登录 + 反向代理 + Tailscale 外网。

### 02 · 网关搭建
- Python 3.14.5 确认、venv 隔离依赖（fastapi/uvicorn/httpx/zstandard）。
- 登录：HMAC 签名会话 Cookie（7 天）、5 次失败锁 5 分钟、审计日志。
- 反向代理：重写 Host/Origin 通过 DSH 的 browser-trust fence；HTTP + WebSocket 双通道。
- 移动端仪表盘 v1（状态/会话/日志/启停）。

### 03 · 修复 WS 403
- 症状：WebSocket 全部 403，处理器不执行。
- 二分定位：**FastAPI WebSocket 处理器参数未标注 `WebSocket` 类型**，依赖解析在运行前抛异常，uvicorn 回 403。
- 修复：所有 WS 参数加类型注解。

### 04 · 外网（Tailscale）
- 电脑/手机组网，MagicDNS `node.<tailnet>.ts.net`。
- 开启 Tailscale Serve（tailnet only）→ `https://node.<tailnet>.ts.net` 全链路实测。
- 修复手机端 `crypto.randomUUID is not a function`（HTTP 非安全上下文）→ 注入 polyfill。

### 05 · 性能优化（流量场景）
- 实测：局域网 0.5s；模拟手机网络（200ms/2Mbps）首开 7.3s。
- 优化链：gzip（体积 -80%）→ immutable 缓存（二次 1.9s）→ 插件预加载 → **仪表盘预热**（登录后后台拉全资源，点开控制台 ~0.5s）。
- 全程真实浏览器（无头 Edge + playwright）验证。

### 06 · 轻量会话浏览
- 数据源：DSH 索引缓存 `session_projcache.json` + `workspace.json`（标题/轮数/token/活跃度全有）。
- 会话文件为 **zstd 多帧拼接**（实测 3.9 万帧/12.9MB），只解压尾部对齐段。
- 尾段只提取"重要节点"：用户提问 + 助手正文（跳过思考）+ 工具摘要。

### 07 · 手机三 Tab UI
- 监控 / 会话 / 日志 底部导航；会话列表直接显示标题、工作区、轮数、token、工作中徽标。
- 会话预览：气泡布局、连续消息合并、过滤统计提示。

### 08 · 轻量回复
- 抓包复刻 Web UI 的 `session.prompt` RPC（信封 `{type, rpcId, method, payload}`）。
- 预览页回复框：乐观显示 → 轮询 tail 等 agent 回复 → 自动刷新。
- 实测：发送后 15 秒内收到回复，全程无需打开完整控制台。

### 09 · 修复乱码
- 上轮用 PowerShell `-replace` 重存 index.html，中文被 GBK 误读成 UTF-8 乱码（"监控"→"鐩戞帶"）。
- 改为 write 工具 + .NET UTF8（无 BOM）写入；静态资源加版本号 `?v=` 强制刷新。

### 10 · 控制台移动端适配
- 注入移动端样式：输入框贴底固定、16px 防 iOS 缩放、消息区留白、详情栏隐藏。
- 侧栏展开即**整屏**（跟随 React 的 `data-sidebar-collapsed` 属性，纯 CSS，不与 React 抢样式）；左上"返回"按钮。
- 点击会话自动收起 + **抑制输入法弹出**（1.5s 窗口拦截自动聚焦）。

### 11 · 会话过滤（预览）
- 服务端过滤思考/工具/上下文注入；每轮只留最终回答；长度上限 400→4000。
- 实测单个会话隐藏 3437 条思考 + 166 条工具调用。

### 12 · 控制台数据层过滤
- 尝试 CSS/JS 隐藏 → 失败（哈希类名、折叠态、正文与思考同容器）。
- 改为**代理改写 `session.history` 响应**：剔除 assistant/chunk（68551 条！）等事件、只留 text 内容块；非真实用户消息（source.kind）丢弃。
- 效果：历史响应 MB→KB 级，加载明显变快。
- 踩坑：`Sxvs8a` 容器同时承载正文与思考，CSS 一刀切曾把最终回复全隐藏（已回滚，只留数据层过滤）。

### 13 · 选择题支持
- 协议：`question/requested` 帧（含 rpcId）→ `/api/respond`（信封 `{type, rpcId, result:{ok, value:{sessionId, answer}}}`）。
- 网关常驻 WS 监听 DSH 事件流（回放 + 实时），捕获挂起问题。
- 预览页选项卡片（单选/多选）→ 提交 → agent 继续执行。
- 全链路实测：提问→卡片→点选→agent 回复。
