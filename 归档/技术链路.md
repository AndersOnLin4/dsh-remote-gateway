# 技术链路

> 端到端链路：手机浏览器 → 认证网关 → DeepSeek Harness（DSH），以及背后每一跳的关键机制。

## 总体架构

```
手机浏览器（浏览器 / Tailscale App）
   │  HTTPS（Tailscale Serve，tailnet only，WireGuard 加密）
   ▼
Tailscale Serve（电脑上，443）        ← 证书 Let's Encrypt（*.ts.net）
   │  http://127.0.0.1:8080
   ▼
FastAPI 网关（0.0.0.0:8080）
   ├─ 登录（HMAC 会话 Cookie + 限速 + 审计）
   ├─ 仪表盘 /dashboard（三 Tab：监控/会话/日志）
   ├─ 会话预览 + 回复 + 选择题（/gw/*）
   └─ 反向代理（根路径 → DSH）
        │  Host/Origin 重写 → 通过 browser-trust fence
        ▼
DSH（仅监听 127.0.0.1:3080，无鉴权，danger-full-access）
   └─ 会话数据：sessions/*/*/session.jsonl.zstd（多帧 zstd）
        └─ 索引：storages/session_projcache.json、workspace.json
```

## 各跳关键机制

### 1. DSH 的浏览器信任栅栏（browser-trust fence）
- DSH 的 `/api` 无鉴权但有栅栏：校验 `Host` 必须为回环或 `trustedHosts` 声明；带浏览器标记时 `Origin` 必须等于 `Host`；拒绝 `sec-fetch-site: cross-site`。
- 网关做法：转发时把 `Host` 重写为 `127.0.0.1:3080`、`Origin` 重写为 `http://127.0.0.1:3080`，即可通过栅栏（回环判定）。
- 代价：特权接口（credentials 等）也随回环判定放行——远程 = 全权限，靠登录墙兜底。

### 2. 反向代理（HTTP + WebSocket）
- HTTP：httpx 流式转发；JSON/文本响应按需 gzip；带 `rev=` 的资源加 `immutable` 缓存；首页 HTML `no-cache`。
- WebSocket：Starlette 接入 → `websockets` 客户端连上游，双向泵；下行帧顺带做问题监听。
- 注意事项：FastAPI WS 处理器参数必须标注 `WebSocket` 类型，否则依赖解析异常导致握手 403。

### 3. 注入机制（代理改写 HTML）
- 对 DSH 首页 HTML 做三次注入：
  1. **polyfill**：`crypto.randomUUID`（HTTP 非安全上下文缺失）+ 右下角"仪表盘"按钮；
  2. **预加载**：boot 配置解析后并行拉取全部插件包；
  3. **移动端样式**：输入框贴底、16px 防 iOS 缩放、侧栏整屏（跟随 `data-sidebar-collapsed` 属性纯 CSS）、工具行隐藏。
- 注入位置必须放在首个 `</script>` 之后（放前面会把 boot 脚本截断，界面白屏——真实踩过）。

### 4. 会话历史数据过滤（数据层）
- 代理改写 `POST /api/session.history` 响应：剔除 `assistant/chunk`（一个会话 6.8 万条！）、思考/工具碎片、`tool/call`、`tool/result`、上下文注入（`agent/inbox/spliced` 及 `source.kind != "user"` 的 user/message）；消息 content 只保留 `type=="text"` 块。
- 效果：历史响应 MB → KB 级；控制台只渲染"提问 + 正文"。

### 5. 会话文件读取（轻量预览）
- `session.jsonl.zstd` 是 **zstd 多帧拼接**（每次追加独立压缩，实测 3.9 万帧）。
- 读取：只取文件尾部 ~1MB → 对齐帧魔数 `28 b5 2f fd` → `read_across_frames=True` 解压 → 逐行解析事件。
- 提取规则：`user/message`（source.kind=user）+ `assistant/message`（只取 text 块，按 turn 保留每轮最后一条）+ `ask_user_question` 选择题；其余全部丢弃并计数。
- 会话列表不读大文件：直接读 `session_projcache.json`（标题/轮数/token/活跃）与 `workspace.json`。

### 6. 发消息（轻量回复）
- 复刻 Web UI 的 RPC：`POST /api/session.prompt`
```json
{"type":"client-request","rpcId":"<uuid>","method":"session.prompt",
 "payload":{"sessionId":"...","mode":"queue","content":[{"type":"text","text":"..."}],
            "clientTimeZone":"Asia/Shanghai"}}
```

### 7. 选择题（问与答）
- 提问：agent 调用 `ask_user_question` → host 经 mux 流下发 `question/requested` 帧（`rpcId` 为问题路由键）。
- 网关**常驻一条 mux WS 连接**监听（回放 + 实时），记录挂起问题。
- 作答：`POST /api/respond`
```json
{"type":"client-response","rpcId":"<问题rpcId>",
 "result":{"ok":true,"value":{"sessionId":"...","answer":{"answers":[{"id":"...","selected":["选项"]}]}}}}
```
- 注意：信封是 `result:{ok,value}` 包裹（写成平铺 `ok/value` 会被拒 `bad-response`）。

### 8. 性能优化链路
- gzip（文本类 -80%）→ `Cache-Control: immutable`（带 rev 资源，二次秒开）→ 首页预加载（并行拉取）→ 仪表盘预热（登录后后台拉全量资源，点开控制台 ~0.5s）。
- 实测（模拟 200ms/2Mbps）：首开 7.3s → 二次 1.9s → 预热后 0.5s。

### 9. 外网（Tailscale）
- 组网：电脑 + 手机同账号；Mag icDNS `node.<tailnet>.ts.net`。
- Serve：`tailscale serve --bg 8080`（tailnet only，不暴露公网），HTTPS 证书由 Tailscale 自动签发。
- 直连 vs 中继：同网络直连（局域网 14ms）；NAT 严格时走 DERP 中继会慢，换网络可恢复直连。

### 10. 登录安全
- HMAC-SHA256 签名 Cookie（7 天，httpOnly/SameSite=Lax）。
- 限速：5 次失败锁 5 分钟（按 IP）；审计日志记录登录与关键操作。
